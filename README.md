# Salesforce Flow Automation: Replacing Slack Alert Tools with Native Flows

## The Problem
Many GTM teams pay for third-party tools to send alerts and automate record updates in Salesforce. These tools can add cost, especially as tools are increasingly adding more features that make them more and more similar and so they create another system to maintain, and split automation logic across platforms.

## The Goal
Rebuild common alert and automation workflows using native Salesforce Flows, organized by object, so the logic lives in one place and is easier to maintain. This can also be something that flows upstream into a warehouse or other platforms integrated with SFDC.

## What This Repo Will Include
- [ ] Design diagram of the automation architecture
- [ ] Inventory of workflows to migrate, grouped by object
- [ ] Flow designs with trigger, criteria, and actions for each
- [ ] Screenshots of the built Flows in a SFDC Developer org
- [ ] Testing approach and results
- [ ] Summary and Conclusion

## Tools used

- Slack
- Miro (design)
- Mermaid (diagrams in this repo) (helps with maintaining records)
